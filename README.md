   $ su mahasiswa
   $ exit

   $ su – mahasiswa
   $ exit

2. Prompt String (PS)
   a. Edit file .bash_profile, ganti prompt PS1 dengan ‘>’. Instruksi export diperlukan dengan parameter nama variable tersebut, agar perubahan
   variable PS1 dikenal oleh semua shell
   PS1=’> ‘
   export PS1
